# Psychology: The science of behavior?

Baumeister et al. (2007) argued that despite psychology's self-image as the science of behavior, that it has become mostly "a science of self-reports and finger movements". However, they reviewed articles from only a single journal (JPSP) using an unclear coding scheme. Additionally, technological advancements since 2007 make it more feasible to collect behavioural data, for example through smartphones, digital trace data, etc. This study examines the prevalence and temporal trends of different modes of measurement, both in terms of what is measured and how it is measured. It does this for 30 journals in 6 subfields of psychology.
